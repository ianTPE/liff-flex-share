Markdown 或 Flex JSON → LINE 卡片

有兩種填法：貼上 Markdown（自動轉成排版好的卡片：粗體、表格、清單，連結列在卡片底部當按鈕）；或直接貼 Flex JSON——內容以 { 開頭就會原樣送出，可填完整訊息（type: flex）或單張 bubble／carousel。按分享後選擇對象，對方會在聊天室直接收到卡片。

🤖 給 AI／自動化流程的操作說明（人類也可參考）
用途
把輸入轉成 LINE Flex 訊息；由人類按「分享卡片」、在 target picker 選對象後送出。
輸入
textarea#md（預設含示範內容，填入前先清空）。內容 trim 後以 { 開頭＝Flex JSON 模式（type 須為 flex／bubble／carousel，原樣送出）；其他＝Markdown 模式，自動轉成 Flex。
填入方式
設定 #md.value 後派發 input 事件，頁面會即時重新解析（也支援從鍵盤／輸入法逐段輸入）。
驗證
#preview 出現「Flex JSON 模式：」＝JSON 已接受；出現「格式錯誤」＝解析失敗；Markdown 模式則顯示排版預覽。實際送出的 Flex 內容在 #json。
送出
button#share 開啟 shareTargetPicker——選對象這步留給人類，AI 不代選。
網址參數
?f=名稱 會載入 flex/名稱.json 的預設卡片（此時 textarea 停用）。
限制
最多 12 張泡泡；單則訊息約 30KB；altText ≤ 400 字；按鈕 label ≤ 20 字。
