自己做一個網頁，從個人 LINE 發出漂亮的卡片

不用官方帳號、不花錢、不用會寫程式，交給 AI 做。做完之後，你在 LINE 裡點一下、選好朋友，對方聊天室就會出現一張有顏色、有按鈕的卡片。

先看看我們要做到什麼

平常在 LINE 裡，我們只能打字、傳照片、傳貼圖。但你可能收過商家或官方帳號傳來的那種卡片：有標題、有底色、下面還有「立即報名」之類的按鈕。那種卡片，一般人的 LINE 並沒有地方可以做。

其實有個辦法可以自己發：請 AI 幫你寫一個小網頁，在 LINE 裡打開它，網頁上按一個按鈕，LINE 就會跳出「要傳給誰」的畫面。選好人、按送出，卡片就用你自己的名義送到對方的聊天室，就像你親手傳的一樣，也不用付任何費用。

這種卡片，LINE 叫它 Flex 卡片（Flex Message）；讓網頁跳出「要傳給誰」畫面的功能，叫 shareTargetPicker。名字先記著就好，後面用到時會再說明。

整件事由三樣東西組成

東西它是什麼從哪裡來
網頁一個叫 index.html 的檔案，上面有「送出」按鈕，也寫好了卡片長什麼樣子AI 幫你寫好，並放上 GitHub Pages（免費把網頁放上網路）
LINE 小程式入口一個專屬網址，在 LINE 裡點開它，網頁才能叫出 LINE 的「要傳給誰」畫面。LINE 把這種在 LINE 裡打開的網頁叫做 LIFF在 LINE Developers（LINE 給開發者用的後台）登記
卡片標題、顏色、內容、按鈕你用平常說話的方式描述，AI 幫你寫進網頁

要準備的只有：一個 LINE 帳號、一個 GitHub 帳號、手機上的 LINE，以及一個能幫你操作 GitHub 的 AI 工具（例如 Claude Code、Codex）。

步驟的順序是：在 LINE 後台建好應用程式 → 登記入口、拿到編號 → 請 AI 做好網頁並放上網路 → 在 LINE 裡試發。因為 AI 做網頁時要用到入口編號，所以編號要先拿到。

1在 LINE 後台開一個「應用程式」

LINE 的所有開發功能都在 LINE Developers 後台。我們要先在裡面登記一個應用程式，LINE 稱它為 channel，之後的入口就掛在它底下。

  1. 打開 LINE Developers Console，用你的 LINE 帳號登入。
  2. 先建一個 Provider。它就像資料夾，名字隨意，填自己的名字就可以。
  3. 在 Provider 裡按 Create a new channel，類型選 LINE Login。
  4. 填名稱、說明，地區選 Taiwan，App types 勾 Web app，同意條款後建立。
⚠️ 類型要選 LINE Login清單裡還有一個 Messaging API，那是官方帳號機器人用的，它底下不能掛我們要的 LINE 小程式入口。選錯了，第 2 步會找不到 LIFF 分頁。

2登記 LINE 小程式入口，拿到編號

入口要知道它連到哪個網頁。網頁雖然還沒做，但網址可以先決定，因為 GitHub Pages 的網址是固定格式：

https://你的 GitHub 帳號.github.io/liff-card/

把「你的 GitHub 帳號」換成你自己的帳號名稱。最後的 liff-card 是等一下 AI 會幫你建立的專案名稱，照用就好。

  1. 回到第 1 步建的 channel，切到 LIFF 分頁，按 Add。
  2. 照下表填：
    欄位填什麼說明
    LIFF app name隨意給自己看的名字
    SizeFull網頁在 LINE 裡以全螢幕打開
    Endpoint URL上面那個網址告訴 LINE 入口要連到哪個網頁
    Scopes勾 profile允許網頁知道是誰在用
  3. 建好後回到 LIFF 列表，把 Share target picker 切成 On。這個開關就是允許網頁叫出「要傳給誰」的畫面。大家最常忘的就是這一步。
  4. 在 LIFF 列表上找到 LIFF ID 這一欄，把它複製下來。它長得像 1234567890-AbCdEfGh，就是這個入口的編號。
✅ 這一步拿到的東西：LIFF ID 和網頁網址先貼在記事本裡。下一步請 AI 做網頁時，兩個都要填進 prompt。

3請 AI 做好網頁，並放上網路

這一步整個交給 AI：寫網頁、在你的 GitHub 建立專案、開啟 GitHub Pages，一次完成。要用能幫你操作 GitHub 的 AI，例如 Claude Code、Codex 這類可以在電腦上執行動作的 AI 工具。第一次使用時，AI 會請你登入 GitHub、同意它存取，照畫面指示做就好。

按下面的「複製」，把整段話貼給 AI。貼之前改兩個地方：把「我的 LIFF ID」和「我的 GitHub 帳號」後面括號裡的說明，換成第 2 步記下的內容。

卡片的部分已經先填好一張範例，第一次可以不改，直接用。想換成自己的卡片，就把「我想要的卡片」那段，用你平常說話的方式改掉。

請幫我做一個網頁，用來從我的個人 LINE 帳號發送 Flex 卡片，並幫我放上 GitHub Pages。我不會寫程式，請你直接完成所有步驟。

【我的 LIFF ID】：（貼上你的 LIFF ID，例如 1234567890-AbCdEfGh）
【我的 GitHub 帳號】：（貼上你的 GitHub 帳號名稱）

【我想要的卡片】
- 標題：LINE Flex 卡片教學
- 主要顏色：LINE 綠色
- 內容：先寫一行「教學重點」，下面列出四點：
  1. 不用官方帳號，從個人 LINE 免費發卡片
  2. 網頁放在 GitHub Pages
  3. 在 LINE 後台登記入口（LIFF）
  4. 請 AI 做好網頁並放上網路
- 按鈕：「看完整教學」，按下去打開 https://iantpe.github.io/liff-flex-share/guide.html
- 對方收到通知時顯示的文字：LINE Flex 卡片教學

【網頁要做到的事】
1. 載入 LINE 的 LIFF SDK（https://static.line-scdn.net/liff/edge/2/sdk.js），用我的 LIFF ID 初始化。
2. 如果還沒登入 LINE，就先導去登入。
3. 頁面中間放一個大的綠色按鈕「選擇好友並送出」，初始化完成之前按鈕不能按。
4. 按下按鈕後，呼叫 liff.shareTargetPicker 跳出 LINE 的選好友畫面，把卡片送出去。
5. 在按鈕下方用中文顯示狀態：載入中、已送出、已取消、失敗原因。如果這個環境不能分享，請提醒我「要在 LINE 裡打開，並在 LIFF 設定開啟 Share target picker」。
6. 手機上看起來要整齊、置中。

【卡片的限制，請務必遵守】
- 卡片用 Flex Message 格式，要有 altText。
- 卡片上的按鈕只能用「打開網址」（uri）這種動作，不能用 postback、message 等其他動作。
- 文字多的地方要設定 wrap: true，才會自動換行。
- 圖片網址必須是 https。

【請幫我放上網路】
1. 在我的 GitHub 帳號建立一個公開（Public）的 repository，名稱叫 liff-card。如果已經有了，就更新裡面的 index.html。
2. 把網頁存成 index.html，放在 repository 的最上層。
3. 開啟 GitHub Pages，來源選 main 分支的根目錄。
4. 等網站上線後，告訴我網址，並確認它是 https://我的GitHub帳號.github.io/liff-card/。如果不一樣，請提醒我要到 LINE 後台把 LIFF 的 Endpoint URL 改成新網址。
5. 需要我登入 GitHub 或按同意時，請一步一步告訴我要按哪裡。

最後請用不懂程式的人也看得懂的話告訴我：以後想換卡片內容時，要怎麼跟你說。

AI 做完會告訴你網址。用瀏覽器打開，看得到「選擇好友並送出」按鈕就成功了。用電腦打開時，頁面可能會要你登入或說無法分享，這是正常的，要到手機 LINE 裡才能用。

如果你的 AI 只能聊天、沒辦法替你操作 GitHub，就直接問它：「你沒辦法幫我上傳的話，請一步一步教我怎麼自己放上 GitHub Pages。」

4在手機 LINE 裡試發一次

入口的網址是 https://liff.line.me/ 後面接你的 LIFF ID。要從 LINE 裡點開才行，最簡單的做法是把這個網址傳到任何一個聊天室，再點它。

  1. 點開後，看到頁面上的綠色按鈕「選擇好友並送出」。
  2. 按下去，LINE 會跳出「Share with」畫面，列出你的群組、好友和聊天室。
  3. 勾一個人，按 Share。頁面顯示已送出，對方就收到卡片了。

想先看看成品？可以在手機 LINE 裡點這個示範：liff.line.me/2011736396-qcyiLRJ3/demo.html。如果打不開，原因寫在下面「別人打不開我的入口」那一題。

5換成自己的卡片

之後想發別的卡片，不用從頭來，直接跟同一個 AI 說，它會改好並更新網路上的網頁，例如：

  • 「把卡片標題改成『週末聚餐』，顏色改成橘色。」
  • 「內容改成時間、地點兩行，按鈕改成『看地圖』，打開這個 Google 地圖網址：……」
  • 「在標題上面加一張圖片，圖片網址是：……」

不知道卡片可以長什麼樣子？LINE 有一個線上工具叫 Flex Message Simulator，左上角 Showcase 有很多現成的卡片樣式（餐廳、收據、行程…）。看到喜歡的，可以截圖給 AI，說「幫我做成像這樣的卡片」。

💡 想讓卡片動起來卡片上的文字不能動，但圖片可以。準備一張會動的 PNG（APNG），跟 AI 說「圖片要播放動畫」即可。

6進階：不用改網頁，直接貼內容發卡片

第 5 步的做法，每換一次卡片都要請 AI 改網頁，再等網頁更新。如果你常常要發不同的卡片，可以改用 liff-flex-share。它是一個現成的網頁：打開後把內容貼進去，按分享就能送出，不用再改程式。

你貼的內容它會怎麼處理
一般文字（Markdown）自動排成卡片。粗體、清單、表格、引用都會保留，連結會變成卡片底部的按鈕
Flex JSON（以 { 開頭）原樣送出。適合從 Flex Message Simulator 複製來、已經設計好的卡片

貼上之後，畫面上會馬上顯示卡片預覽。格式有錯也會直接提示，不用等送出才發現。

裝到自己的帳號

我的入口還在開發中狀態，別人打不開，所以要複製一份到你自己的 GitHub。一樣交給 AI：把下面這段話貼給它，改掉括號裡的說明。

請把 https://github.com/ianTPE/liff-flex-share 複製一份到我的 GitHub 帳號，做成公開（Public）的 repository。我不會寫程式，請你直接完成所有步驟。

【我的 LIFF ID】：（貼上你的 LIFF ID）
【我的 GitHub 帳號】：（貼上你的 GitHub 帳號名稱）

1. 把 index.html 裡的 LIFF_ID 換成我的 LIFF ID。
2. 開啟 GitHub Pages，來源選 main 分支的根目錄。
3. 網站上線後告訴我網址，並提醒我到 LINE 後台，把 LIFF 的 Endpoint URL 改成這個新網址。
4. 需要我登入 GitHub 或按同意時，請一步一步告訴我要按哪裡。

AI 做完後，到 LINE 後台把 Endpoint URL 改成它給的新網址。LIFF ID 和入口網址都不用換，之後一樣從 https://liff.line.me/你的 LIFF ID 打開。

試試看

在 LINE 裡打開入口，把預設的示範內容清掉，貼上這段：

# 週末聚餐

- **時間**：週六晚上 6:30
- **地點**：信義區的餐廳
- 有吃素的人先跟我說

[看地圖](https://maps.google.com)

按「分享卡片」、選好友、送出。對方會收到一張有標題、粗體和清單的卡片，底部有一個「看地圖」按鈕。

💡 常發同一張卡片把卡片的 Flex JSON 存成 repository 裡的 flex/名稱.json，之後在入口網址後面加上 ?f=名稱（例如 https://liff.line.me/你的 LIFF ID?f=weekend），就會直接載入這張卡片，不用每次重貼。名稱只能用英文小寫、數字和連字號。

7會遇到的狀況

按鈕為什麼只能開網址？

卡片是用你個人帳號送出的，對方按按鈕時，LINE 沒有一個「機器人」可以接收。所以凡是要傳資料回去給機器人的按鈕，都要改用官方帳號發卡片才行。能直接打開網頁的按鈕則沒有問題。

按鈕按下去會用這個方法能不能做
打開一個網址（加入 Zoom、填報名表、看活動頁）✅ 可以，網址最長 1,000 字
回傳資料給機器人❌ 要官方帳號
替對方送出一句話❌ 要官方帳號
複製一段文字❌ 要官方帳號
選日期時間❌ 要官方帳號

其他常見狀況

你看到的為什麼怎麼辦
頁面說「無法分享」Share target picker 沒開，或不是從 LINE 裡點開檢查第 2 步的開關；確認是從 liff.line.me/… 網址點開
頁面說 LIFF 初始化失敗網頁裡的 LIFF ID 填錯，或第 2 步填的網址和 AI 建好的網址不一樣對照第 2 步的 LIFF ID 和 Endpoint URL；網址不一樣時，把 Endpoint URL 改成 AI 給的網址
別人打不開我的入口剛建好的 channel 處於「開發中」（Developing），只有你自己和你加的測試人員能打開在 channel 頁面上方改成 Published，或在 Roles 分頁把對方加成測試人員。收卡片的人不受影響，卡片誰都看得到
按送出後跳出錯誤卡片內容有地方不符合 LINE 的格式把畫面上的錯誤訊息整段貼給 AI，請它修正
改了網頁，LINE 裡還是舊的LINE 會暫存網頁，GitHub Pages 大約 10 分鐘才更新在網址後面加 ?v=2、?v=3，每次換個數字
找不到某位好友對方在 LINE 隱私設定裡關了「允許外部應用程式存取」請對方打開，或改用一般方式傳
選人畫面裡沒有自己這個畫面本來就不能傳給自己，也沒有 Keep測試時傳給家人，或開一個只有你和一位朋友的小群組
找不到社群（OpenChat）這個功能不支援社群—

可以一次發給很多人嗎？

可以在選人畫面一次勾好幾個人或群組。但每一次都要你自己打開、勾選、按送出，沒辦法讓程式在背後自動一直發。需要自動發送，就要改用官方帳號，而官方帳號主動發訊息是要算錢的。

這個方法以後還能用嗎？

LINE 在 2025 年公告，建議新做的 LIFF 改成「LINE MINI App」，兩者會慢慢整合。目前用 LINE Login channel 建的 LIFF 仍然正常運作。

接下來可以這樣做

建議第一次先不改卡片，只把 LIFF ID 和 GitHub 帳號填進去，讓 AI 做出範例卡片，發給一位家人或朋友。確定整條路走得通，再請 AI 換成你自己的卡片。這樣萬一出問題，比較容易分辨是設定沒做好，還是卡片內容有問題。這是建議的練習順序，不是必要步驟。
